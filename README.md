# 🎧 Moodify – AI Mood Based Music App

Moodify is an intelligent web application that detects your mood using your webcam and generates a personalized music playlist based on how you feel in real time.

It combines **AI-based emotion detection** with **music recommendation logic** to create a unique and engaging user experience.

---

## 🚀 Features

✨ Real-time **Face Mood Detection**  
🎵 Smart **Music Recommendations based on mood**  
📊 **Mood History Tracking**  
🔥 Dynamic **Playlist Generation**  
📈 **Mood Insights** (streaks, sessions, top mood)  
🔐 Secure **Authentication (JWT + Cookies)**  


## 🛠️ Tech Stack

### 💻 Frontend
- React.js (Vite)
- Tailwind CSS
- Axios

### ⚙️ Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- Multer

### 🧠 AI / Tools
- Face Detection Model (for mood recognition)
- ImageKit (media handling)
